## 产品概述
修复法律问答系统中检索/重排序链路的受保护条款保障缺陷，使含概念词（如"拘留"）的跨法规查询能稳定召回处罚种类定义条款（如第十条）和行为+量刑条款（如第二十六条），不依赖 rerank 模型对这些条款的打分。

## 核心问题
1. **min_score 过滤致命缺陷**：受保护条款（definition/behavior_penalty）的 min_score 仅放宽至 0.75 倍（0.15），但对于"行为定性定义"和"行为+量刑"条款，rerank 模型经常给出低于 0.15 的分数，导致它们在过滤循环（274-312行）中被完全丢弃，根本不进入 scored 列表。
2. **配额保障只在 overflow 中搜索**：当受保护条款被 min_score 过滤后，配额保障逻辑（390-447行）在 overflow（scored[top_n:]）中找不到它们，保障失效。
3. **behavior_penalty_max=2 截断**：过滤循环中 behavior_penalty 最多保留 2 条，如果先进入的是不相关的 behavior_penalty 条款（如第三十六条危险物质），第二十六条（扰乱秩序）被跳过，后续配额保障在 overflow 中也找不到它。
4. **rerank instruct 不匹配场景**：英文通用搜索指令"Given a web search query, retrieve relevant passages that answer the query"无法引导模型理解中文法律检索需要同时覆盖行为规定与处罚依据。
5. **配额保障不总是执行**：仅当 len(scored) > top_n 时才触发，当 scored 恰好 ≤ top_n 时完全不检查概念词配额。



## 技术栈
- 后端：Python + FastAPI + qwen-plus LLM（阿里云百炼）
- 重排序：qwen3.7-text-rerank（DashScope API）
- 策略配置：config/policy.json 数据驱动
- 测试：pytest + mock

## 实现方案

### 核心策略：三层保障增强

**第一层：min_score 完全豁免**
受保护条款（definition + behavior_penalty）完全跳过 min_score 检查，只要 API 返回了分数就进入 scored 列表。不再使用 0.75 倍放宽，而是直接设为 0。

**第二层：全量分数查找表（_all_scored）**
在过滤循环之前，从 API 返回的全部 results 中构建 `{candidate_id: {candidate + rerank_score}}` 查找表。这张表包含所有候选（无论是否通过过滤），作为配额保障的终极回退数据源。

**第三层：配额保障无条件执行 + 全量回退**
- 移除 `if len(scored) > top_n:` 前置条件，改为始终执行配额检查
- 当 overflow 中找不到所需条款时，回退到 _all_scored 全量查找表搜索
- 从 _all_scored 中选取 rerank_score 最高的匹配项直接插入 top_n

### instruct 优化
将英文通用指令改为中文法律检索专用指令，强调需要同时覆盖行为规定、处罚种类定义和处罚依据条款。通过 policy.json 配置化，支持运行时调整。

### 设计原则
- 不硬编码任何特定法条，所有逻辑基于通用角色分类（definition/behavior_penalty）和概念词匹配
- 保留现有同source限流、跨法规替换、behavior_penalty_max 等机制对非受保护条款的约束
- 不增加额外 LLM 调用，零额外成本和延迟

## 关键代码结构

全量分数查找表的数据结构：
```python
# 所有候选的 rerank 分数查找表（不受过滤影响）
# key: candidate id, value: candidate dict with rerank_score
_all_scored: dict[str, dict] = {}
for r in results:
    idx = r["index"]
    score = float(r.get("relevance_score", r.get("score", 0.0)))
    cid = candidates[idx].get("id", str(idx))
    _all_scored[cid] = {**candidates[idx], "rerank_score": score}
```

配额保障回退逻辑（kind_definition 示例）：
```python
# 先在 overflow 中搜索
kind_def_candidates = [c for c in overflow if ...]
# overflow 找不到时，回退到 _all_scored 全量查找
if not kind_def_candidates:
    top_ids = {c.get("id") for c in top}
    kind_def_candidates = [
        c for cid, c in _all_scored.items()
        if cid not in top_ids
        and _is_protected_role(_classify_role(c.get("metadata", {})))
        and "种类" in (c.get("text", "") or "")
        and any(kw in (c.get("text", "") or "") for kw in concept_keywords)
    ]
```
