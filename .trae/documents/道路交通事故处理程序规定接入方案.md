## 3. 假设与决策

1. **共用单个 collection**：两部文档同属道路交通安全领域，检索为 BM25+向量+RRF 双路召回，置于同一 `road_traffic_law` collection 即可让「妨害程序性问题」与「实体法条」被同时召回，无需拆分集合。
2. **多文档自动发现**：语料源改为「项目根目录下所有 `.docx` 文件」，无需维护文档清单，自动纳入新增法规（含已存在的 2 个 docx）。
3. **source 使用清理后的文件名**：`source = 去 `.docx` 后缀 + 去掉末尾 `_YYYYMMDD` 日期后缀`，得到干净来源名「中华人民共和国道路交通安全法」「道路交通事故处理程序规定」，同时用于向量 id 与展示。
4. **id / source 结构变更需一次性重建索引**：旧数据用 `source=...docx` 生成 id，与新 id 结构不一致，实施后需删除 `chroma/` 目录触发全量重建（见验证步骤）。
5. **不再每次启动删除 collection**：改为「维度不匹配时重建；空库时首次入库；否则保留」，避免每次启动重复入库的冷启动开销。

### 4.2 app/ingestion.py —— 解析清理 + 多文档入库

1. 新增来源名清理函数：

```python
def _clean_source_name(path: Path) -> str:
    name = path.stem
    name = re.sub(r"_\d{8}$", "", name)  # 去掉 "_20210429" 日期后缀
    return name
```

2. 修复目录跳过判断（替换掉现有死代码 `if "目" == text and "录" in p.text`）：

```python
# 目录起始标记（兼容 "目录"/"目 录"/"目　录" 等变体）

    in_toc = True
    continue
```

3. 清理章/节标题内部空白（U+2002 及普通空格），生成干净 `section_header`：

在设置 `state.chapter` / `state.section` 时，对标题做 `re.sub(r"[\u2002\s]+", "", title.strip())`，例如标题变为 `第一章 总则`、`第六章 调查 / 第二节 现场处置和调查`。

4. 重构 `ingest()` 为多文档 upsert（**不再 `delete_collection`**）：

```python
def ingest() -> int:
    settings = get_settings()
    paths = settings.docx_full_paths
    if not paths:
        raise DocumentNotFoundError("项目根目录下未找到任何 .docx 文档")

    import chromadb
    client = chromadb.PersistentClient(path=str(settings.chroma_full_dir))
    collection = client.get_or_create_collection(
        name=COLLECTION_NAME,
        metadata={"hnsw:space": "cosine", "hnsw:construction_ef": 100,
                  "hnsw:search_ef": 16, "hnsw:M": 16},
    )

    embedding_model = get_embedding_model()
    total = 0
    for path in paths:
        articles = parse_docx(path)
        if not articles:
            continue
        source = _clean_source_name(path)
        documents = [a.text for a in articles]
        metadatas = [{"article_no": a.article_no,
                      "section_header": a.section_header,
                      "source": source} for a in articles]
        ids = [_make_id(source, a.section_header, a.article_no) for a in articles]
        embeddings = embedding_model.embed_documents(documents)
        collection.upsert(ids=ids, documents=documents,
                          metadatas=metadatas, embeddings=embeddings)
        total += len(articles)
    return total
```
