# law_helper 法律咨询助手

基于 RAG（检索增强生成）的中文法律智能问答助手：根据用户提问，从内置法条库中检索相关法律条文，结合大模型生成回答。

## 它能做什么

- **法律咨询问答**：围绕刑事、交通事故、人身权益等领域，检索相关法条并给出回答；超出范围的问题会礼貌拒答
- **文档上传问答**：上传 docx / pdf 等法律文书，就文档内容进行提问
- **多轮对话**：支持连续追问，会话自动保存，并自动生成会话标题
- **流式输出**：回答以流式方式逐字呈现
- **访问控制**：通过授权链接（token）访问，管理员可在本地管理授权

## 技术栈

FastAPI 后端 + React/Vite 前端 + 大语言模型 + 向量检索，支持 Docker 部署。

## 快速启动

### 本地运行

注意: 需要自己配置env文件

```bash
python run.py
```

脚本会自动启动前后端：

- 后端：http://127.0.0.1:8000
- 前端：http://localhost:5173

按 `Ctrl+C` 一次性退出两个服务。

### Docker 部署

在服务器上执行：

```bash
cp deploy.env.example deploy.env   # 填写部署配置
bash deploy.sh
```

## 配置

本地运行主要依赖 Python 环境与 `requirements.txt`；服务器部署相关配置见 `deploy.env.example`（含镜像仓库地址、命名空间等）。
